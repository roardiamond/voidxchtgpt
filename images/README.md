1. Create folder `images/` if it does not exist (this file already creates the path).
2. Download or copy the files listed above from the old repo:  
   https://github.com/roardiamond/VOIDXHUB
3. Place them inside `images/` with the **exact same filenames**.
4. Commit and push.

The HTML pages already point to `images/filename.jpg` and have fallbacks if an image is missing.
